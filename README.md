ProceVision AI
AI-Powered Procedural Error Detection using CNN-LSTM
ProceVision AI is an AI-powered video analysis system designed to detect procedural errors in instructional or procedural videos.

The system analyzes temporal video sequences using a CNN-LSTM model and identifies potential procedural errors at both the temporal-sequence level and step level.

🚀 Features
Video-based procedural analysis
CNN-LSTM temporal sequence modeling
Step-level procedural error detection
Temporal error region identification
Prediction confidence scores
Error sequence navigation
Related procedural step identification
Video evidence for detected errors
JSON analysis report generation
Professional PDF report generation
Interactive Streamlit dashboard
